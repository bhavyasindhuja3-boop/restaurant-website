## Run locally
Open `index.html` in a browser.

## Deploy with GitHub Pages
1. Create a repository on GitHub.
2. Upload these files to the repository root.
3. Open Settings → Pages.
4. Select Deploy from a branch, `main`, and `/ (root)`.
5. Save and wait for your live Pages URL.

This is a static front-end demo. Images load from Unsplash and require internet. Booking, ordering and payments are not connected.
